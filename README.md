# PARTICLES
This is a pure test application.
While I do adhere to linter rules strictly and TypeScript is configured at a very high level of strictness,
there is no class system, no engine, or any kind of "architecture" here.

I consider this project as a learning exercise and a playground for testing various techniques and approaches
to WebGPU particle systems.

Due tu incompleteness and the fact that this is "bad code" in the sense of software engineering,
I don't want this code to be used as a reference or for training AI models, as it may lead to bad practices
being learned or propagated.

## Disclaimer
This is a learning/test project with low code quality. It is NOT intended for production use.
Usage for AI training is strictly discouraged to prevent model degradation.
